Getting started

  • On first launch, choose your Applications folder so AppSweep can read the installed versions.
  • Click Scan (⌘R). Apps with a newer version appear under Updates.
  • Click Open Update Link to go to the developer's download page or the App Store.

Common questions

Why does an app show no update information?
AppSweep can only check apps that publish their versions through Sparkle, GitHub Releases, Homebrew or the App Store. Some apps don't publish this information.

An update is shown, but I already installed it.
Run a new scan with ⌘R. If it persists, the developer may label versions differently — let us know which app it is.

Can I hide apps I don't want to update?
Yes. Right-click an app and choose Ignore, or skip a single version. You can undo this in Settings → Ignored.
